1.2 위치 정보 처리

댕이랑은 v1에서 사용자의 원본 GPS 좌표와 산책 경로를 Firebase, 자체 서버, Cloud Functions에 저장하거나 전송하지 않습니다.

  • 원본 GPS 좌표는 단말기에서만 사용합니다.
  • 위치는 날씨 격자 변환, 홈 동네 라벨 표시, 가까운 장소 거리 계산, 산책 거리 계산에 사용됩니다.
  • 홈 동네 라벨 표시는 외부 역지오코딩 API 없이 앱에 포함된 로컬 장소 주소 데이터와 현재 위치를 단말에서만 비교해 처리합니다.
  • 날씨와 대기질 정보를 조회하기 위해 단말에서 변환한 기상청 격자값(nx/ny) 또는 에어코리아 측정소명은 공공 API 요청에 사용될 수 있습니다.
  • 현재 위치 주변 지도를 표시하기 위해 OpenStreetMap 타일 좌표와 IP가 타일 제공자에게 전달될 수 있습니다.
  • Firebase, 자체 서버, Cloud Functions에 원본 lat, lng, path, 위치 샘플 배열을 저장하지 않습니다.
  • 산책 종료 후 서버에는 산책 시작/종료 시각, 거리, 활동 시간, 반려견 ID와 산책 당시 반려견 이름, 날씨 요약, 평가/메모 같은 요약 기록만 저장됩니다.
  • 경로 저장, 장소 자동 감지, 서버 위치 처리 기능은 v1에 포함하지 않습니다.

산책 알림은 사용자가 설정에서 켠 경우 Android 단말의 로컬 알림 예약 기능으로 처리하며, FCM 토큰 저장, 서버 발송, 서버 위치 기반 알림 계산은 v1에서 사용하지 않습니다.

단, 산책 기록 저장 시 네트워크가 불안정하면 Firebase SDK 동작에 따라 산책 요약 기록이 단말에 전송 대기 상태로 남았다가 네트워크 복구 후 자동 동기화될 수 있습니다. 이때도 원본 GPS 좌표와 산책 경로는 전송 대기 대상이 아닙니다. 앱 삭제, 앱 데이터/캐시 삭제, 단말 초기화, 장기 오프라인 상태에서는 전송 대기 중인 기록이 사라질 수 있습니다.

  • 사용자 요청에 따른 산책 평가와 메모 저장

  • AdMob 광고 표시와 광고 관련 정책 준수

1.5 개인정보의 보유와 삭제

  • 반려견 프로필, 산책 요약 기록, 찜한 장소는 사용자가 삭제하거나 계정 삭제를 요청할 때까지 보관합니다.
  • 사용자가 앱 내 삭제 기능을 이용하면 해당 데이터는 삭제됩니다.
  • 앱 내 계정 및 데이터 삭제 기능은 반려견 프로필, 산책 요약 기록, 찜한 장소와 Firebase Anonymous Auth 계정을 삭제합니다.
  • 외부 계정 삭제 요청 경로의 정책상 필수 여부와 처리 방식은 Google Play 지원 티켓 답변 후 확정합니다.

1.7 개인정보 보호 조치

  • Firebase/Firestore 접근은 사용자별 UID 경로로 분리합니다.
  • Firestore 보안 규칙으로 사용자가 자신의 데이터만 접근하도록 제한합니다.
  • 산책 기록 저장 필드는 요약값 allowlist로 제한하고, 원본 좌표와 경로 저장을 금지합니다. 산책 당시 반려견 이름은 기록 표시용 선택 스냅샷으로 저장될 수 있습니다.
  • 통신은 Firebase, Google, 공공 API의 HTTPS 통신을 사용합니다.
  • API 키와 운영 광고 ID는 코드에 하드코딩하지 않고 빌드 주입값으로 관리합니다.

이용약관

2.1 목적

본 약관은 댕이랑이 제공하는 모바일 앱 서비스의 이용 조건과 권리, 의무, 책임 사항을 정하는 것을 목적으로 합니다.

2.2 서비스 내용

댕이랑은 다음 기능을 제공합니다.

  • 날씨와 대기질 정보를 활용한 산책 컨디션 표시
  • 반려견 프로필 관리
  • 주변 반려견 동반 가능 장소 및 지도 표시
  • 산책 거리와 시간 기록
  • 산책 기록, 평가, 메모 저장
  • 광고 표시
  • 정보 출처와 법적 안내 제공

서비스 범위와 기능은 운영 상황, 정책 변경, 기술적 사유에 따라 변경될 수 있습니다.

2.3 서비스 성격과 면책

댕이랑의 산책 컨디션과 추천 표현은 재미와 참고를 위한 정보입니다. 의료, 수의학, 안전 판단을 대체하지 않습니다.

  • 반려견의 건강 상태, 나이, 질병, 수술 이력, 기저질환에 따라 실제 산책 가능 여부는 달라질 수 있습니다.
  • 건강 이상이 있거나 판단이 어려운 경우 수의사와 상담해야 합니다.
  • 날씨와 공기 정보는 외부 공공 API에 의존하므로 지연, 오류, 누락이 있을 수 있습니다.
  • 사용자는 앱 정보를 참고 자료로만 활용하고, 최종 판단은 사용자 책임으로 합니다.

2.4 이용자 의무

이용자는 다음 행위를 해서는 안 됩니다.

  • 허위 정보 입력 또는 타인의 정보 무단 입력
  • 앱의 정상 동작을 방해하는 행위
  • 광고를 부정하게 클릭하거나 클릭을 유도하는 행위
  • 법령, 공공질서, 타인의 권리를 침해하는 행위
  • 앱을 상업적 또는 불법적 목적으로 악용하는 행위

2.5 위치 기능

앱은 사용자가 직접 시작한 산책 기록, 주변 장소 거리 표시, 날씨/대기질 기반 컨디션 계산을 위해 위치 권한을 사용할 수 있습니다.

  • v1은 "앱 사용 중" 위치 권한과 사용자가 시작한 산책 중 Foreground Service만 사용합니다.
  • 항상 허용 위치 권한과 ACCESS_BACKGROUND_LOCATION은 요청하지 않습니다.
  • 산책 중 원본 GPS 좌표와 경로는 서버에 저장하지 않습니다.
  • 산책 종료 시 좌표는 폐기되고, 서버에는 거리/시간/날씨요약/평가 같은 요약값만 저장됩니다.

2.6 광고

앱에는 Google AdMob 광고가 표시될 수 있습니다.

  • 광고는 앱 운영과 서비스 제공을 위한 수익화 목적으로 표시됩니다.
  • 광고 요청 가능 상태와 사용자 지역의 적용 규정에 따라 UMP 동의 흐름이 표시될 수 있습니다.
  • 산책 중 화면, 산책 Foreground Service 활성 중, 산책 종료 직후 저장 대기/평가 흐름에는 광고를 노출하지 않는 것을 원칙으로 합니다.
  • 사용자는 광고를 부정하게 클릭하거나 반복 클릭해서는 안 됩니다.

  • 앱 업데이트, 보안 점검, 정책 변경
  • 법령 또는 플랫폼 정책 변경

2.8 데이터 삭제

  • 반려견 프로필과 산책 기록은 사용자가 직접 삭제할 수 있습니다.
  • 앱 내 계정 및 데이터 삭제 기능은 반려견 프로필, 산책 요약 기록, 찜한 장소와 익명 계정을 삭제합니다.
  • 외부 계정 삭제 요청 경로와 이메일 수동 삭제 기준은 Google Play 지원 티켓 답변 후 확정합니다.
  • 앱 삭제만으로 서버 저장 데이터가 즉시 삭제되지 않을 수 있습니다.

2.9 책임 제한

앱은 외부 공공 API와 사용자 단말 환경에 의존합니다. 법령상 허용되는 범위에서, 서비스 제공자는 외부 데이터 오류, 네트워크 장애, 사용자의 판단 또는 이용 방식으로 발생한 손해에 대해 책임을 제한할 수 있습니다.
