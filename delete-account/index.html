계정 및 데이터 삭제 요청

이 페이지는 댕이랑의 계정과 서버 저장 데이터를 삭제하는 방법을 안내합니다.

앱에서 직접 삭제하기

앱을 사용할 수 있다면 앱 내부 삭제가 가장 빠르고 정확한 방법입니다.

  1. 댕이랑 앱을 엽니다.
  2. 더보기 > 설정으로 이동합니다.
  3. 게스트는 이 기기 데이터 삭제, 이메일 계정 사용자는 이메일 계정 삭제를 선택합니다.
  4. 안내를 확인한 뒤 삭제를 확정합니다.

게스트 데이터는 단말 로컬에서 삭제됩니다. 이메일 계정 삭제를 완료하면 Firebase Auth 계정과 해당 계정에 연결된 서버 저장 데이터가 삭제됩니다.

이메일로 삭제 요청하기

앱을 사용할 수 없거나 외부에서 삭제 요청이 필요한 경우 아래 이메일로 요청해 주세요.

  • 요청 이메일: biz.honeyholic@gmail.com
  • 제목 예시: 댕이랑 계정 및 데이터 삭제 요청
  • 포함 정보: 가입 이메일 주소와 계정 소유 확인에 필요한 정보. 불필요한 민감정보는 요청하지 않습니다.
게스트 사용자는 서버 계정이 없고 데이터가 단말 로컬에만 저장됩니다. 이메일 계정의 서버 저장 데이터 삭제가 필요한 경우 앱 내부 삭제 기능을 우선 이용해 주세요.

삭제 대상

계정 삭제 요청이 처리되면 다음 데이터가 삭제됩니다.

  • 이메일 계정의 Firebase Auth 계정
  • 이메일 계정에 저장된 반려견 프로필
  • 이메일 계정에 저장된 산책 요약 기록
  • 이메일 계정에 저장된 찜한 장소

서버에 저장하지 않는 정보

댕이랑은 원본 GPS 좌표와 산책 경로를 서버에 저장하지 않습니다. 현재 위치는 단말기에서 산책 컨디션 계산, 주변 장소 거리 표시, 산책 거리 계산에 사용한 뒤 서버로 전송하지 않습니다.

이메일 요청은 접수 후 계정 소유 확인을 거쳐 처리 결과를 회신합니다. 본인 확인 완료 후 지체 없이 처리하며, 특별한 사정이 없으면 30일 이내 처리 결과를 회신합니다.
